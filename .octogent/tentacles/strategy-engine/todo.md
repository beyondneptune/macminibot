Backlog for `strategy-engine`. Architecture is the daily-rebalance MV optimizer with vol-targeting and turnover control (see `CONTEXT.md`). Each epic is self-contained and agent-sized.

Respect half-days (early close goes into every `TargetPosition.valid_until`). Single entry point that all subsequent epics depend on. Includes idempotency: replays of the same `as_of` produce identical `decision_id`s.

- [ ] **Covariance estimator with Ledoit-Wolf shrinkage + EWMA window** — 252-day EWMA-weighted dollar-bar returns matrix → `Σ_shrunk = (1-δ)·Σ_sample + δ·F` with constant-correlation target `F`. Emit `cond(Σ_shrunk)` to observability every call. Provide a diagonal fallback path used when `cond > 1e6`. Unit-tested against `sklearn.covariance.LedoitWolf` for parity.

- [ ] **MV optimizer (cvxpy + tiered solver: ECOS / OSQP / HRP)** — Implement the quadratic program from CONTEXT with L1 + small-L2 turnover penalty and gross / per-name / net constraints. Non-optimal status falls back to HRP and alerts.

- [ ] **Vol-target scaler (σ_target = 12% annualized)** — Compute `σ_p = sqrt(w*' · Σ_shrunk · w*) · sqrt(252)`, then `w_final = w* · (σ_target / σ_p)`. Cap scaling factor at `[0.25, 4.0]` to prevent silly leverage on near-zero vol days. Track realized vs target vol over a rolling 63-day window and emit tracking-error metric to observability.

- [ ] **Turnover gate (no-trade band + global turnover ceiling)** — After optimizer + vol-target: if `|Δw_i| < 0.5% NAV` for a name, freeze `w_final_i := w_prev_i`. If total `||w - w_prev||₁ > 1.0`, proportionally scale the trade vector down to 1.0 and log a "turnover-blowup" event. Both thresholds are config — exposed to `control-plane`.
