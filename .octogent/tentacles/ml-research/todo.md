- [ ] **Drift monitor (two-stage: marginal + multivariate)** — Daily post-close job. **Stage 1 (marginal)**: KS-test each of the 12 features' last-21-days live distribution vs the most-recent-training-fold distribution; emit p-values to `observability`; advisory alert if any feature p < 0.01 for 5 consecutive days. **Stage 2 (multivariate / dependence)**: (a) PSI on the top-3 PCA scores of the standardized feature matrix (PCA fit on training fold; decile-bucketed against training-fold quantile edges; alert if any of the top-3 PCs has PSI > 0.25 for 3 consecutive days); (b) Frobenius-normalized correlation-matrix distance `||C_live - C_train||_F / ||C_train||_F`; alert if > 0.3 for 3 consecutive days. Only Stage 2 alerts trigger a `control-plane` pause — marginal drift is advisory because it is often benign re-scaling, while correlation drift is the regime-change signal that actually invalidates the model. Reference: Siddiqi 2006 *Credit Risk Scorecards* for PSI; cycle-3 refinement in CONTEXT.md.
